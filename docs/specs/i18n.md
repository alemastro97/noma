# Interface language

**Status:** Shipped (Unreleased) · **Phase:** 4

## Scope

NOMA's interface in **English** or **Italian**. What the user says or types is never translated; spoken-language settings for Whisper and spoken answers stay separate (Settings → Voice).

1. **Setting.** Settings → Appearance → _Interface language_: **Match system** (default), **English**, **Italiano**. Also in the ⌘K palette (_Language: …_). "Match system" means Italian when the first preferred macOS language is Italian, English otherwise.
2. **Everywhere at once.** The main window and every floating window (orb, voice overlay, quick capture, orb panel, toasts) switch **live**, without a restart. The menu-bar menu is relabelled at the same moment, and native notifications (reminders, morning brief, evening recap, focus end, "remind me before") are sent in the chosen language.
3. **Dates follow the language.** Weekday and month names, "Today/Oggi", relative times ("in 2h" / "tra 2h") and repeat descriptions ("every Monday" / "ogni lunedì") come from the active language; the 24 h clock is kept in both.

## Design

- **Strings.** `src/copy.ts` is the English source; `src/copy.it.ts` implements the same `CopyBundle` type in Italian, so a missing or extra key fails `tsc`. Every user-visible string lives there (including the former inline aria-labels, palette commands, AI status chip, date words and repeat descriptions — `uiCopy`, `dateCopy`, `recurrenceCopy`).
- **Runtime switch.** The exports of `copy.ts` (`copy`, `settingsCopy`, …) are live proxies over the active language, so components keep importing them unchanged. Strings must be read at render time, not captured at module load.
- **Locale state.** `src/i18n/locale.ts` holds the preference (`system | en | it`), mirrored in `localStorage` (`noma.language`) so each window starts in the right language without a flash, and in the backend setting `ui.language` (source of truth, read by Rust). `LocaleRoot` re-mounts a window's tree when the language changes; stores live outside React, so navigation and data survive. `<html lang>` follows the language.
- **Propagation.** `settings_set("ui.language")` relabels the tray menu (`tray::relabel`) and emits `ui:language` with the new value to every window; windows also follow `storage` events and the browser's `languagechange` (for "Match system"). The mock backend emits the same event.
- **Rust strings.** `src-tauri/src/i18n.rs` (`Lang`) resolves the setting (system language from `AppleLanguages`, else `$LANG`) and holds the tray labels and notification texts.

## Open questions

- Rust error messages surfaced as-is (e.g. a shortcut already owned by another app) are still English.
- Window titles of the floating panels (read by VoiceOver's window chooser) are fixed at creation and stay English.
